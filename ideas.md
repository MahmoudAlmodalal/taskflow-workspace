# Taskflow design direction

The demo follows a **Quiet Command Center** direction: editorial modernism translated into a focused productivity dashboard. Warm paper surfaces, deep ink typography, muted moss, and Saffron Signal (`#E7A928`) establish an identity that feels precise without becoming clinical.

The layout uses an asymmetric command center: orientation on the left, execution in the middle, and a paper-margin insight column on the right. Interactions are immediate and reversible. Task completion is a clear state change, filters update in place, and the responsive layout collapses the side rails rather than squeezing the core task flow.
